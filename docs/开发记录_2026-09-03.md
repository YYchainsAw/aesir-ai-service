### 新增语音端点 `/v1/voice/command`

音频 → ASR → 既有解析层 → `ParseCommandResponse`，与文本端 `/v1/commands/parse` 共享契约 v0.1。

- `app/services/transcribers/`：新增强定制转写层
  - `base.py`：`ASRBackend` 抽象 + `TranscriptionError`
  - `mock.py`：`MockASRTranscriber` 返回 `AESIR_ASR_MOCK_TEXT`

- `app/api/v1/voice.py`：multipart `file`(WAV 16k mono 16bit) + 可选 `request_id`/`context_json`；`request_id` 非 UUID → 422，context 非法 JSON → 422，转写抛错 → 502
- `app/config.py`：`get_asr_backend()` / `get_asr_mock_text()`
- `.env.example`、`main.py`、`requirements.txt`（`python-multipart`）同步更新

### 测试

`tests/test_voice.py` 6 条（mock / 桩 / 空转写 / 422×2 / 502），全链路 42 通过。

修复过程踩到的两个测试坑：
1. Form 字段名必须对齐路由参数名（发送 `request_id`/`context_json` 而非旧名）。
2. 路由模块级 `from ...factory import get_transcriber` 已绑定名字，monkeypatch 需打 `app.api.v1.voice.get_transcriber` 而非 factory 模块属性。
