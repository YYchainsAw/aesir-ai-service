## 完成

### 1. 专用转写端点 `POST /v1/speech/transcribe`

- 新增 `app/api/v1/speech.py`：只做「音频 → 文本」，不接解析层；与组合端点
  `/v1/voice/command` 并存，长期保留（UE5_模型服务联调技术规范 §6.3 要求）。
- 请求：multipart 字段 `audio`（WAV 16kHz/单声道/16bit）+ 可选 `request_id`（UUID，
  原样回显，缺省服务端生成）+ 可选 `locale`（预留）。
- 响应：`{request_id, text, language}`；未识别 `text` 为空串（HTTP 200），转写
  错误 502，非法 request_id 422。
- 复用现有 transcriber 工厂（mock / faster_whisper 均可插拔）。
- 新增 `tests/test_speech_api.py`（5 例，桩注入不加载模型）。全量测试
  **49 通过 + 2 真机冒烟跳过**。

### 2. 真人声调优脚手架 `scripts/asr_eval.py`

- 约定：真人录音放 `data/asr_samples/`，**文件名即期望文本**
  （如 `艾琳撤退并优先保命.wav`，去标点后评测）。
- 功能：逐样本输出转写结果、字错误率（CER，编辑距离实现）与耗时，末尾汇总
  平均值；支持 `--model/--beam/--no-vad` 参数扫描，用于选 8GB 显存下最优组合。
- **待办：真人录音样本尚未提供**，录制后即可跑评测。
