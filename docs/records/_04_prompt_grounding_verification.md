## 事实依据与拦截

| 内容 | 可使用的依据 | 不足以支持它的内容 |
| --- | --- | --- |
| 玩家已陈述的事实 | 本轮玩家原话、已注入且未被纠正的记录 | 模型自行补充的细节 |
| 当前世界/自身状态 | 本次快照、成功的相关状态查证 | 旧助手回复、无关记忆或仅有模糊主题 |
| 声称亲自检查过路线 | 明确记载该角色完成该行动的 observation/shared_experience 记录，或成功查证中明确对应的行动记录 | 当前天气/HP/MP 快照、行程计划、任意一条不相关记忆、模糊印象、失败查证 |
| 角色能力 | 当前实际能力目录 | few-shot 中的情境细节或模型猜测 |

新增策略 `style-policy-003` 对已报告的“路我大致看过了”“我已经检查过这条路线”等完成态声称进行检查；无当前快照或状态查证时，也拦截“我这边魔力还算充裕”一类自身状态声称。非流式走已有的一次重试/最终降级路径，不提交违规回复及事实；流式在完整校验失败时不提交最终 meta，已发送的 delta 无法撤回，保持原接口边界。

新增 18 项回归覆盖：静态前缀与类别覆盖、原始路线案例、无关/玩家陈述/条件计划不能放行、有效观察记录能放行、计划/否定/疑问不误杀、安全重试、成功/失败查证、无快照自身状态、快照不能证明过去路线行动、流式不提交违规结果且不复用旧查证。

这些是针对已知高风险表达的确定性拦截与提示词来源约束，不是任意自然语言的通用事实蕴含判断。存在快照不代表每个定性形容都已证明；后续正式质量采样仍需检查语义与数值一致性。

## 目标服务器：仍缺连接条件

本轮实际执行 SSH 的只读连接检查，`baota-server` 返回无法解析主机。随后复查用户 `.ssh`、known_hosts、项目文档/工作记录及 IDE 连接元数据，未找到与该项目关联的有效 SSH 连接。没有尝试登录无法关联用途的已知主机，也没有向其他服务器转移 Key。

4. 停止并重启本次隔离服务进程；按 recovery 契约查询原 run 历史，并重新 context/bind，确认旧凭据与旧请求不能重放副作用。
