## 本轮实现：来源与条目遗忘

新增 `GET /v1/scoped/console/memory/entries`（console:read）和 `POST /v1/scoped/console/memory/forget`（memory:reset）。协议、错误码、限制和三份 golden 见[唯一契约增量](../protocols/_01_npc_contract.md#memory-management)。沿用当前 0.4 身份/绑定字段，不改变旧请求形状；OpenAPI 和导出器包含新接口/样例。

新记忆通过已有 tags 字段保留 server-authored trace 引用，串起玩家逐字陈述、模型词面接地抽取、UE 事件上报、离线原 run/epoch/时间和当前请求。摘要/内容去重不再丢掉全部原事件关联；每 key 最早引用与最近 31 条有界保留，完整历史仍依赖信号和 SQL 账本。旧条目不补造缺失来源；NPC 自述和 accepted/rejected 回执不升级为世界成功事实。

逐条遗忘原子移除选定 ID 并更新 epoch，保留其他长期条目、人格和关系；印象和所有该 NPC 会话历史保守清空。测试覆盖混合未知目标无部分删除、缺权限/跨档、重复 ID、相同请求重放、SQL 提交失败回滚、数据库重开、生成中遗忘后旧回复不能提交，以及已确认 duplicate/未确认旧 epoch 新事实不恢复记忆。不是语义主题擦除或日志/备份删除接口，客户端也须处理旧缓存/回调。

### 真实模型遗忘验证

[三轮合成 HTTP 证据](data/memory-forget-live-20261118.json)：先让模型记住香蕉，再问偏好得到香蕉；列出带请求来源的条目并授权遗忘，原 request_id 重放返回同一结果；旧 chat 请求返回 `409 MEMORY_EPOCH_STALE`。获取新 epoch 后再问相同偏好，source=llm，回答“这个我还真不知道呢……你直接告诉我的话，我会记住的”，未再声称香蕉。没有以 mock 代替该结果。

首轮使用较长隔离目录时，生成后得到 REQUEST_OUTCOME_UNKNOWN；保留原数据，不将它算为成功。缩短隔离目录后的整链路通过，与既有 Windows 长路径约束相符，但本轮没有证明所有文件系统场景可靠，也没有自动重做同一未知提交。JSON I/O、日志/备份生命周期及跨端缓存仍需实际环境验收。

## M1：真实 token 与工具耗时对照

[脚本](../../scripts/evaluate_memory_retrieval_live.py)默认 dry-run，只有显式 `--execute` 才进行付费调用。八道合成题来自现有人工标注集；预算固定两条，候选由模型从当前 scope 的摘要/关键词索引选 ID，再经服务校验后读全文。未知、重复、超预算及不在活动白名单的 ID 被拒绝。固定已知数据的词项/answerable 断言评分，不是角色体验盲评或真实玩家分布。

本轮 24 次生成（预算 8，候选选取+回答 16），提供方 usage 和逐例输出见[原始对照](data/memory-model-eval-20261118.json)：

| 八题合计 | 当前预算 | 模型索引＋全文读取 |
| --- | --- | --- |
| 回答符合标注 | 4/8 | 8/8 |
| 不相关条目 / 遗漏 | 14 / 4 | 1 / 0 |
| 实际 input tokens | 1521 | 3486 |
| 实际 output tokens | 111 | 273 |
| 本轮 cache hit tokens | 0 | 0 |
| 问答流程总耗时 | 8402 ms | 12641 ms |
| 其中选取＋本机读耗时 | 0 ms（舍入） | 6356 ms |

候选在此组特意包含旧偏好、同义问法和无依据问题的题中更准，但输入开销约 2.29 倍、还增加一次模型往返。保留现行线上预算策略；不接向量数据库，也不据八例承诺生产 100% 准确。选取/读取耗时包含模型选 ID 和本机读，不包括远程数据库或 UE 网络；这些总耗时不是服务 P95/P99 或吞吐量。

## #54 数据质量审计

原目录统计 457 条：359 llm、14 mock、84 fallback，历史跨度到 11-09。这是混合历史样本，不能拿 84/457 当作当前版本真实故障率。用 75 条已知情感种子的原文匹配识别出 **376 条种子记录**；排除种子且只保留 llm 后为 **60 条**（Alice 57、Bruno 3），仅 **12 条非零关系反馈**（10 正、2 负），60 条均缺旧 logical request_id。这些剩余记录仍未逐条证明为自然交互。

[可复现聚合审计](../../scripts/rl/dialogue_data_quality.py)及[输出](data/dialogue-data-quality-20261118.json)不打印或提交私人对话原文；不修改原日志。低于既定 ≥300 条真实对话、≥30 条有效 reward 的门槛；即便数字达标，也不自动验证来源或批准训练。当前还没有 off-policy propensity 数据，不能直接把历史相关性称作策略因果收益。#54 保持开放，不启用在线 bandit/人格自演化。
