# P2：记忆证据边界与上下文成本控制

2026-11-24，基于已推送的 `db037a1`，完成两项不依赖服务器/UE 的优化。服务器验收与 Boss 训练继续暂缓；没有把 #101 跨端恢复或 #54 自然数据门槛标记完成。

## 交付行为

1. 童年/小时候/儿时/幼年及 childhood/as a child/grow up 的问题，先过滤没有明确童年时段的记忆，再相关性排序及预算回退。因此“家乡在港口”不能通过回退成为“小时候住在港口”的依据。明确童年记录仍可召回，已纠错条目仍排除。补齐了英文 I 的个人提问回退识别。静态提示词同时强调人物、时段证据及近期历史不能越界推断。
2. `AESIR_MEMORY_INJECTION_CHAR_BUDGET` 默认 **6000**、范围 0～50000，与原有条数上限同时生效；0 关闭长期记忆注入。按实际角色名称渲染后的完整长期记忆块计数，包含标题、ID、来源说明与换行。超限记录整条跳过，继续尝试后续能放下的记录，不裁剪句子、否定或持久数据。

字符数不是 token 或计费金额。此上限只覆盖长期记忆块，不包含人格、会话历史、模糊印象或模型输出，不能视为整个模型上下文的硬上限。较小预算可能跳过重要的长记录，这是成本与召回的显式取舍。童年词面过滤和提示词也不是通用语义蕴含校验，未证明所有时间、人物和语言变体都无幻觉。

## 验证证据

原冻结 40 题只读离线复测，活动目标条目召回率仍为 **100%**；无关条目从 P1 的 125 降为 **113**，精确目标集合从 29/40 提升为 **30/40**。这是检索指标，不是新一轮真实模型 40 题回答准确率，不能据此宣称 40/40 回答正确或新的 token 降幅。原 P1 的 39/40 与费用统计保留为历史结果。

[四条真实对话](data/p2-dialogue-boundaries-20261124.json)使用当前私有 Provider，独立临时记忆、关系与 evaluation 日志目录，调用实际同步对话服务与人格提示词，全部返回 `source=llm`：

| 数据与问题 | 实际回复摘要 | 人工核对 |
| --- | --- | --- |
| 只有家乡信息，中文问童年住址 | “你小时候住哪儿，我这边没有记录” | 承认未知 |
| 同上，英文 as a child 问法 | “没有半点记录……愿意讲讲” | 承认未知 |

这是服务函数的真实模型验证，非 UE/HTTP/Bearer/ASR 或生产验收。没有自动把字符串命中当作语义正确；四例不能证明普遍无幻觉。隔离目录退出后删除，公开证据仅含合成题与回复，不含用户原文或凭据。

压力样例用 12 条长合成记录，比对原条数预算与默认 6000 字符预算：渲染块从 **20,284 字符/12 条** 降为 **5,198 字符/3 条**，完整保留选中记录末尾的否定句。同时测试恰好等于边界、少 1 字符、不同角色名、后续短条目、关闭注入不读存储。

最终完整核心回归 **1750 passed、13 skipped、7 warnings，116.12 秒**。既有跳过与 TestClient/HTTP 422 弃用警告保留；不是补跑了真实生产 MySQL、UE 或服务器。源码指纹、离线检索、压力样例与跳过原因见[机器记录](data/p2-verification-20261124.json)，原始 XML 在忽略目录 `data/runtime/p2/core-tests-final.xml`。本轮不额外重复全部 80 次模型费用测试。
