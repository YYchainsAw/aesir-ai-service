### 1. 批次 B 实施内容

#### B-01：记忆路径增加 `game_id` 命名空间

**问题**：`app/services/memory/store.py` 中记忆目录直接拼在 `<npc_id>` 下，无法满足跨游戏隔离；`game_id:companion_id` 在 Windows 路径非法。

**改动**：
- `MemoryStore` 增加 `game_id: str = "aesir"` 参数，目录结构改为 `<memory_root>/<game_id>/<npc_id>/memory.json`。
- `get_memory_store(npc_id, *, game_id="aesir", root=None)` 缓存 key 同步包含 `game_id`。
- 新增迁移脚本 `scripts/migrate_memory_to_game_namespace.py`，把本地 `data/memory/<npc_id>` 迁移到 `data/memory/aesir/<npc_id>`（运行 1 个角色目录）。

#### B-02：意图解析层唤醒词/游戏名/角色名外置

**问题**：`intent_parser.py` 写死 `_WAKE_WORDS = ("艾莉", "艾琳", "alice", "eirin")`；`llm_intent.py` system prompt 写死《Aesir》+ 艾莉。

**改动**：
- `data/companions/primary_companion.yaml` / `secondary_companion.yaml` 的 `identity` 段新增 `game_name`、`wake_words`、`self_reference_blacklist`。
- `app/services/companion/profile_repository.py` 解析并暴露 `game_name`、`wake_words`、`self_reference_blacklist`。
- `app/services/tactical/intent_parser.py`：`parse_text_to_intent(text, *, wake_words=None)` 接受外部唤醒词，默认保持旧值兼容。
- `app/services/tactical/llm_intent.py`：新增 `build_system_prompt(profile)`，游戏名/角色名从 profile 读取；用字符串替换（非 `str.format`）避免 JSON 示例中的花括号被误解析。
- `app/services/tactical/llm_intent.py`：`parse_intent_with_source(text, *, companion_id=None, client=None)` 加载对应 profile 的唤醒词与 prompt。
- `app/api/v1/tactical.py`：`command_tactical` 从 `combat_context.companion.id` 取 `companion_id` 传入意图解析门面。

#### B-03：战术确认与事件反应按角色路由

**问题**：`acknowledgement_service.py` 与 `event_policy.py` 仍使用无参 `get_profile()`，只读主队友。

**改动**：
- `create_tactical_acknowledgement(intent, companion_id=...)` 改为 `get_registered_profile(companion_id)`。
- `_load_reaction(event_type, *, companion_id, section=...)` 改为按角色读取事件反应。
- `event_policy.py` 全部 `_evt_*`、`_evaluate_world_combat`、`_evaluate_lifestyle` 传入对应 `companion_id`。
- `app/services/parsers/command_parser.py` 旧版 `/parse-command` 路径也补充 `companion_id`（从 `context.agents[0].id` 取，默认 `companion.alice`）。

#### B-05：话题黑名单中的角色自指词外置

**问题**：`app/services/memory/topics.py` 的 `_TOPIC_BLACKLIST` 包含「艾莉/爱莉/alice」等角色自指词。

**改动**：
- `_TOPIC_BLACKLIST` 只保留通用元语言碎片；移除角色自指词。
- `is_blocked_topic` / `extract_topics` 增加 `self_reference_blacklist` 参数。
- `MemoryStore` 初始化时加载对应 profile 的 `self_reference_blacklist`，在 `_merge_mentions_locked` 与 `migrate_verbatim_to_impressions` 中使用。

#### B-06：世界观知识库按 `game_id` 分目录

**问题**：lore 知识库无游戏维度，单文件 `data/world/lore.yaml` 无法满足跨游戏接入。

**改动**：
- 创建 `data/lore/aesir/lore.yaml`，从 `data/world/lore.yaml` 迁移现有内容（`data/world/lore.yaml` 保留一段时间供回退，但主入口已指向新路径）。
- `app/services/skills/tools.py`：`_LORE_PATH` 改为 `_lore_path(game_id)`；`get_lore(game_id)`、`search_lore(query, game_id)` 按命名空间缓存。
- `ToolRequest` 增加 `game_id` 字段；`_lore_query` 使用 `request.game_id`。
- `run_lookup(..., game_id=...)` 透传；`llm_dialogue_service.py` 调用查证时传入 `self._profile.game_name.lower()`。
