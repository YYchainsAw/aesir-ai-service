### 5. 422 根因（已实锤）

BP_AesirGameMode EventGraph 里 `ResolveTacticalIntentForTest` 节点的 IntentId / TargetId / Timing / NormalizedText 引脚**无连线无默认值**（空字符串），CombatContext 来自默认构造变量。空请求体重放抓到 3 条校验错：

- `intent.intent_id` = '' 不在 11 个枚举白名单
- `intent.timing` = '' 不在 immediate/on_condition/when_possible
- `combat_context.captured_at` = '' 不是 ISO-8601

**结论**：这是 UE 侧测试蓝图没接参数，不是 Python 缺陷；Python schema 按契约正确拒绝。修法在 UE 侧：BP 引脚接上真实意图（如 `retreat_and_survive` / `immediate`）或删掉这个 BeginPlay 自动调用。

### 6. 联调最大瓶颈（实测确认）

**UE 项目里没有任何 .umap 关卡**（`find Content -name "*.umap"` 为空；DefaultEngine.ini 指向的 `/Game/Aesir/Maps/L_OpenWorld` 包不存在）。standalone game 模式两次启动都因 "Failed to load package" 退出。

后果链：
- 无关卡 → PIE 世界里只有 BP_AesirGameMode，无 PlayerCharacter / Companion
- `CompanionChatSubsystem::BuildWorldContext` 找不到玩家/艾莉 Actor 直接 return false
- 3 秒心跳 `SendAgentStep(FString(), false)` 从不发请求 → `/v1/agent/step` 真实流量为零
- 玩家对话框 `SendChatMessage` 也无从触发

Python 侧生产路径已用 UE 对齐的请求体（从 C++ 源码逆向）自测通过：`/v1/commands/parse`（retreat, source=llm）、`/v1/agent/step`（200 全字段）。缺的是 UE 侧内容：一个含 PlayerStart + BP_Alice 的可玩关卡。

## 深夜场二：主动对话联调，发现路由分流问题

### 1. 方法

UE standalone game 再起（心跳稳定 200），同时用 `scripts/jiadiao_dialogue_probe.py` 模拟玩家对艾莉说 5 轮话（按 UE 真实 `/v1/agent/step` payload，scene + text），再对 `/v1/companion/chat` 发同样 4 句闲聊做对照。

### 2. 核心发现：agent/step 不处理闲聊

| 玩家输入 | /v1/agent/step | /v1/companion/chat |
|---|---|---|
| "早上好啊" | rule, INTENT_UNRECOGNIZED, "我没听清" | llm 1025ms "早啊！你来得正好..." |
| "你是AI吗" | rule, INTENT_UNRECOGNIZED | fallback "让我想想。你先说说看法？" |
| "还记得上次Boss吗" | rule, INTENT_UNRECOGNIZED | llm 1776ms "我脑子里翻不出具体画面..." |
| "你真烦闭嘴" | rule, INTENT_UNRECOGNIZED | llm 1056ms "行，那我先不说话了" |

**根因**（`app/api/v1/agent.py:388-411`）：agent/step 带 text 时只走 `parse_intent_with_source`（11 个意图白名单），intent=None 直接返回"我没听清"。闲聊不在白名单 -> 全拒。`/v1/companion/chat` 是独立的 LLM 对话路径，本身健康。

**UE 侧问题**：`CompanionChatSubsystem::SendChatMessage` (line 75) 把所有玩家输入（含闲聊）全走 `SendAgentStep(text, true)` -> `/v1/agent/step`，没有"指令 vs 闲聊"分流。

### 3. 对话质量观察（companion/chat 链路健康时）

- LLM 人设在线：诚实不编造 Boss 记忆（"翻不出具体画面，你提一句我就接上"）；对敌意得体（"行，那我先不说话了"）
- 第 2 轮"你是AI吗"触发 style_guard 出戏术语拦截（"AI"=元语言），重试后 fallback 到 YAML 候选回复--设计行为，但回复略回避

### 4. 待修问题清单

| 优先级 | 问题 | 修法位置 |
|---|---|---|
| P0 | agent/step 收到闲聊文本硬拒，无 LLM 对话降级 | Python `app/api/v1/agent.py` intent=None 分支 fallback 到 companion dialogue |
| P1 | UE SendChatMessage 不分流指令/闲聊 | UE `CompanionChatSubsystem.cpp` 按文本类型选 /v1/agent/step vs /v1/companion/chat |
| P2 | style_guard 拦截"AI"后 fallback 回复偏回避 | `data/personas/aesir/alice.yaml` 候选回复调优 |

## 深夜场四：FIX-11 / UE-01 / FIX-13 三连修复（测试完毕后开工）
