# PlantUML 图与源文件

该目录保存 UML-01～13 的可编辑 `.puml`；同名 PNG 按用户安排位于 `../png/`。图表清单和阅读入口见 [UML 索引](../README.md)。

文件命名格式：

```text
<两位编号>-<主题>-<as-is|to-be>.puml
../png/<两位编号>-<主题>-<as-is|to-be>.png
```

每张图必须在注释中写明 UE、Python 服务提交号和所用证据编号。

修改 `.puml` 后同步在 `png/` 生成同名 PNG，保持用户目录安排。部分脚本的 `@startuml` 内部名称与文件名不同，导出时仍须以脚本文件名为准，避免出现一图多名。

2026-10-08 新增 UML-11～13：从 NPC Spec v1.1 提取的用例图、分析类图与对象图。三张图采用 `to-be` 后缀表示需求目标，并记录原 Spec 日期、提取日期及两仓参考版本；图中的正例不代表当前 UE 已完成执行。Spec 正文通过相对链接引用本目录，每图独立保存。
