# 网页展示接入计划

项目结构待定，暂停开发。

## 展示目标

网页定位为面向体验者的服务演示客户端。它能让体验者不安装 UE 就体验对话、查看转写与服务返回的信息，也便于你单独验证服务端。但服务端是否稳定、身份是否正确，仍由 API 负责，网页不能掩盖 fallback、伪造动作回执或把 mock 当真实模型。

建议保留两种明确模式：

| 模式 | 作用 | 是否需要运行 Python |
| --- | --- | --- |
| 离线样例展示 | 说明项目、角色、典型请求和录制/固定演示结果 | 不需要；必须标明是样例 |
| 实时服务体验 | 用户输入文本，浏览器调用现有 scoped API，展示真实 source 和错误 | 需要；真实 LLM/ASR 还需各自可用 |

### 第一版范围

1. 项目介绍与能力边界。
2. Alice/Bruno 选择与文本聊天。
3. 等待、发送失败、取消、重连状态；区分 mock/llm/fallback。
4. 少量预设意图演示：展示 directive 及被拒原因，**不生成假的 UE executed 回执**。
5. 可选的关系阶段展示，优先复用业务回复已有字段；完整记忆/调试权限不提供给普通用户。
6. 页面标明演示模式及固定服务版本。

第二版再接录音/上传与转写。浏览器录音输出不应直接假定是服务要求的 16kHz/单声道/16-bit PCM WAV，需要确定转换方式。VAD/TTS/在线训练/自定义世界模拟器都不作为第一版前置。

## 6. 分仓后的职责

独立仓库名称为 `aesir-server-web`。结构确认前暂停开发；本计划仅规定服务端接入需求。

```text
aesir-ai-service          现有服务仓：业务规则、身份/授权、存储、LLM/ASR、OpenAPI、样例
aesir-server-web          网页仓：页面、交互、API 客户端、会话状态、演示数据、前端测试
```

前端框架可选 Vite + TypeScript 搭配团队熟悉的 React/Vue；不需要为了展示引入 SSR、账户产品或另一个通用后端。前后端按契约交接，网页由独立仓维护。

### 服务端交接内容

- 固定 OpenAPI 与后端兼容提交，复用 `scripts.export_ue_handoff` 的契约/样例输出方式；前端维护者不复制业务实现。
- 提供开发用的 context→bind→chat、v0.5 轮询、错误、重连与 voice 表单样例。
- 明确哪些 endpoint 是用户业务入口、哪些仅供调试；不要为网页便利开放 legacy 或全量记忆管理。
- 为受控演示分配独立身份/存档/数据目录和调用预算。development 固定身份可用于单机主持演示，不能对多个远程体验者冒充独立认证。
- 约定服务端与前端各自版本；接口形状变化时同步更新契约、黄金样例和前端客户端。

前端不重新实现意图解析、人格规则、关系计分或请求幂等；这些仍由 Python 单一实现负责。

## 7. 不上架也需要怎样运行

推荐先做本机开发服务器：浏览器→前端开发代理→环回 8011 API。使用前端工具的代理可让浏览器只访问一个来源；Vite 的 `server.proxy` 支持按路径代理。构建后的静态站点需要另配反向代理，不能假定开发代理会随 dist 自动生效。[Vite 官方代理说明](https://vite.dev/config/server-options.html#server-proxy)

如果浏览器直接从另一个端口访问 API，两个端口就是不同来源。当前 Python 应用未注册 CORS 中间件，需明确允许的开发来源、方法和请求头，或使用同源代理；独立仓库本身不解决跨域问题。[MDN CORS 说明](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/CORS)

模型供应商 key、数据库密码只留在服务端。网页接触的是用户业务会话凭据，不是 LLM key；不能把供应商 key 放进 `VITE_*` 环境变量，因为它会打包进客户端代码。[Vite 环境变量说明](https://vite.dev/guide/env-and-mode.html)

不需要公开域名、云托管或备案动作才能先本机展示。

## 8. 网页方案与服务端 Issue 的关系

- 实时聊天依赖 #116/#119 的固定可用文本服务；静态展示不依赖真实 LLM。
- 实时语音依赖 #98 的实际服务能力；不因按钮能录音就宣布转写通过。
- 远程多人访问依赖身份、配额和 #99 的相应发布门禁；纯本机演示可先采用受控开发配置。
- 网页可帮助验证错误、取消、source、请求去重与服务端恢复，但不关闭 UE 动作、游戏包或 Boss 实战任务。
- 内部 console.html 可以继续作为开发工具维护，不需要为了新网页立即删除。新网页应使用 scoped 业务 API，不沿用它的旧调试数据通道。
