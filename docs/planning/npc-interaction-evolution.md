## 用例补充与状态保证

本节补充SDD对应步骤，不增加第8个技术动作型UC。原UC成功保证和当前实现差距继续有效。

| 服务UC | 扩展步骤/异常出口 | 对应整组UE用例 |
| --- | --- | --- |
| UC-01 陪伴对话 | 请求入队并固定本轮作用域/上下文版本；可取消生成，完成校验后提交完整回复。流中失败保留可见片段及未完成状态，不将半截回复记作完整承诺。语音闲聊后置增加受确认文本合成、播放及打断；播放结束不等同生成结束 | NPC-UC01 |
| UC-02 战术指令 | 稳定逻辑命令身份、条件目录和失效边界；UE复核、去重、真实回执。迟到/重复不能形成当前新动作；未支持条件明确澄清/拒绝 | NPC-UC02 |
| UC-03 语音指令 | 采集/转写完成后才进文本解析；临时文本供展示，否定句/目标/技能含糊不得猜执行。外部ASR失败可改文本；纯ASR成功不表示指令接受 | NPC-UC03 |
| UC-04 自主建议 | 在现有规则候选/禁打断/仲裁外补事件筛选、合并、容量和寿命；仍从心跳响应返回至多一条建议或none，不将采纳方案解释成每次心跳调用LLM | NPC-UC04 |
| UC-05 世界事件 | 以原作用域持久去重、确认及补拉，区分事实归档与当前动作。旧遭遇事实可归档原局，但不得借重连在新局施法；来源/确认状态参与记忆与关系处理 | NPC-UC05 |
| UC-06 查询解释 | 关联生成、工具、取消、已播范围与实际动作回执；无记录返回未知，不用当前状态替代历史，查询仍受身份/作用域和保留策略限制 | NPC-UC06 |
| UC-07 重置记忆 | 在现有清理范围上增加持久重置屏障及缓存/队列失效；与并发旧代写入协调。失败/部分完成如实报告；不重建人格、关系或扩大为全日志擦除 | NPC-UC07 |

对话取消不是撤销已经发生的世界事实。已确认旧局事实可按原身份归档；未完成回复不能伪造为已告知或已兑现。生成、播放、命令接受、动作执行和命中是不同状态，不能共用一个success。现回执仍是`accepted/executed/rejected/expired/cancelled`；started/hit/completed、取消端点、游标/重置字段等须协议版本化后实现，不因本文出现概念而视为当前枚举或API。

D4不扩大BR-02的重试路径：表达校验失败的重试在相应输出确认前执行；SSE已有可见输出后失败采用中断/错误终态。当前style guard在全文后执行，已发delta无法收回。TTS首版从meta确认的reply_text合成；若要边生成边播，先设计句级校验与最终修正语义，并记录时延代价。

M3的条目级更新/遗忘需明确授权与实际操作范围；不能由一次LLM工具调用任意重写人格、关系或另一存档。M4继续遵循BR-DEP-06，混合事实的关系贡献与记忆清理分别确认，不能靠换event_id再次计分。AIRI文档同步的edit-wins可恢复删除，不满足本项目的清记忆语义。

## 新增验收定义

以下全部未执行。每次记录服务/UE提交、配置/人格/策略、协议和迁移版本、供应商、硬件/并发、样本及原始证据，运行结果只写[验证记录](../logs/verification-records.md)。既有NFR/SC指标保持，新增阶段时延先明确起止和预算，不照搬AIRI默认数值或以服务响应证明UE已表现。

| ID | 场景 | 通过条件 |
| --- | --- | --- |
| AT-EVO-01 | 连续聊天、明确替代意图、切角色/读档/重试后释放旧回包 | 排队/替代规则可解释；旧代不更新当前UI、会话、关系或动作；已确认旧事实仅归档原作用域 |
| AT-EVO-02 | 工具超预算、首输出前暂时故障、首输出后断流及重复完成通知 | 工具次数/截止生效；只在允许边界重试；已输出内容标未完成而不自动整轮重放；完整回复/关系贡献不重复提交 |
| AT-EVO-03 | 按键录音、临时/最终转写、否定句、目标/技能含糊、空音频/设备切换/外部ASR失败 | 临时文本不执行；最终文本复用校验；原始/修正可追溯，含糊澄清；失败可文本输入且无遗留采集任务 |
| AT-EVO-04 | 第二句先合成、玩家打断、迟到音频、回声、TTS失败及流式最终修正 | 按序播放且只播已确认文本；停止当前及待播/生成，旧片段不复活；已播范围如实，回声不触发新命令；失败仍有字幕 |
| AT-EVO-05 | 高频重复快照、普通受击、紧急边沿、过期事件、禁打断和云端离线 | 状态合并/寿命/队列容量生效；不逐事件调用LLM；优先级不越UE规则；本地已实现基础行为继续，无主动服务推送 |
| AT-EVO-06 | 当前预算检索与索引按需读对照；偏好纠错；玩家主张/NPC输出/UE事实混合 | 记录准确率、误召回/遗漏、token和工具耗时后选方案；来源和确认状态可追溯；不把猜测或NPC自述写作已发生事实 |
| AT-EVO-07 | 条件指令登记后断网、目标死亡/过期/新遭遇、重复请求/乱序回执 | UE本地监听并执行前复核；失效拒绝；同逻辑命令不重复启动；accepted不当命中，失败回执不生成成功经历 |
